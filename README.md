# حاسبة الزكاة الشاملة | Anubisland

تطبيق ويب تقدمي (**PWA**) متكامل يعمل على اللاب توب والتابلت والموبايل لحساب جميع أنواع الزكاة على منهج **أهل السنة والجماعة**، مع رسوم بيانية تفاعلية ودليل ثقافي وتعليمي.

## المميزات الرئيسية
- **10 أنواع للزكاة**: المال والنقد، الذهب والفضة والحلي، الأسهم، عروض التجارة، الزروع والثمار، بهيمة الأنعام، العقارات، الديون المرجوة، الركاز، وزكاة الفطر.
- **رسوم بيانية تفاعلية**: رادار النصاب، مخطط دائري لتوزيع الزكاة، ومقارنة الأصول بالزكاة.
- **متعدد العملات واللغات**: الجنيه المصري (افتراضي) + SAR, AED, KWD, QAR, USD, EUR, GBP، مع دعم العربية والإنجليزية والوضع الليلي.
- **دليل ثقافي وتعليمي**: أهمية الزكاة، شروطها، أوقات إخراجها، آدابها، ومصارف الزكاة الثمانية.
- **تطبيق ويب تقدمي (PWA)**: قابل للتثبيت والعمل دون اتصال بالإنترنت.
